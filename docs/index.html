How this was measured

  • Servers were started over stdio with the official MCP Python SDK and asked for tools/list. No tool was called.
  • Token counts use tiktoken o200k_base on each tool as an OpenAI-style function definition. They are approximate: every provider has its own tokenizer and tool template. The billed prompt tokens per model come from the provider's own usage field.
  • Requests were written by a model from each tool's description and can be edited in the intents YAML. Written by mistral:ministral-8b-latest, then reviewed by hand.
  • Each model got the same system prompt asking for exactly one tool call, temperature 0, one try per request. With one or two requests per tool, a single answer moves a percentage by several points: read differences of a few points as noise.
  • Monthly cost uses list input prices and ignores prompt caching, which many agents use and which lowers the real bill.
